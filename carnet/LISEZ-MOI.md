# Carnet d'entraînement — le site

Le même carnet que dans Claude (Séance, Programme, Progression, Journal, Nutrition), sous forme de site indépendant :
une adresse à vous, un mot de passe, et les mêmes données sur le téléphone, la tablette et l'ordinateur.

## Le mettre en ligne avec Claude Code

1. Décompressez ce dossier sur votre ordinateur.
2. Ouvrez-le dans Claude Code.
3. Demandez-lui :

   > Lis CLAUDE.md et mets ce site en ligne en suivant la section « Mise en ligne ».
   > Guide-moi pour les étapes que je dois faire moi-même.

Vous aurez deux choses à faire vous-même : créer (ou ouvrir) un compte Cloudflare, et choisir le mot de passe du site.
À la fin, Claude Code vous donne l'adresse du site.

## Ce qu'il faut savoir

- **Données de départ** : le site démarre avec votre programme, vos aliments, vos repas et vos séances
  tels qu'ils étaient dans l'application Claude au moment où ce dossier a été créé.
- **Deux carnets séparés** : une fois le site en ligne, il ne se synchronise pas avec l'application dans Claude.
  Choisissez l'un des deux pour noter vos séances.
- **Un seul mot de passe** : toute personne qui le connaît voit et modifie le même carnet.
- **Connexion Internet nécessaire** pour ouvrir le site et enregistrer. Une séance en cours de saisie reste sur l'appareil
  tant qu'elle n'est pas enregistrée.
- **Synchronisation** : un changement fait sur un appareil apparaît sur les autres en 30 secondes environ, ou dès qu'on revient sur la page.
- **Écran d'accueil** : dans le menu du navigateur du téléphone, « Ajouter à l'écran d'accueil » installe le carnet comme une application.
- **Sauvegarde** : demandez à Claude Code « fais une sauvegarde de la base » (commande `npm run sauvegarde`).
